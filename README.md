# GreenScape Lawn & Landscape — Premium Website Design

A complete, modern, high-converting, and realistic multi-page website built for **GreenScape Lawn & Landscape**, a residential lawn care and landscaping business based in Lakeland, Florida.

Developed as a professional web design portfolio showcase for digital agency **AppVanta**.

---

## 🌿 Brand Identity & Design System

- **Business Name:** GreenScape Lawn & Landscape
- **Location:** Lakeland, Florida, USA (Polk County)
- **Tagline:** *"Beautiful Lawns. Reliable Care."*
- **Aesthetic:** Editorial American service-business layout, natural Florida residential photography, balanced forest green and warm gold accents, clean typography with high contrast.
- **Color Palette:**
  - Primary Forest Green: `#183D2D`
  - Secondary Green: `#427A46`
  - Off-White Background: `#F5F6F1`
  - Warm Gold Accent: `#D9B76A`
  - Charcoal Text: `#252B26`
- **Typography:**
  - Headings: [Manrope](https://fonts.google.com/specimen/Manrope) (Bold & Semibold)
  - Body: [Inter](https://fonts.google.com/specimen/Inter) (Regular & Medium)

---

## 📄 Pages Included

1. **Homepage (`index.html`)**: Complete 9-section conversion funnel:
   - Full-width Florida residential lawn hero with dual CTAs
   - Company introduction & 3 core value pillars
   - 4 Featured service cards (Mowing, Design, Sod, Cleanups)
   - The GreenScape difference (Why Choose Us)
   - Portfolio preview masonry grid
   - 3-Step service workflow
   - Polk County locality chips (Lakeland, Winter Haven, Auburndale, Plant City, Bartow)
   - Final high-impact CTA banner
   - Detailed sitemap footer & concept demo disclosures
2. **About Us (`about.html`)**: Company philosophy, Florida climate & turf management, craftsmanship values, and expectations.
3. **Services (`services.html`)**: Deep-dive breakdowns of 6 residential services with alternating editorial layouts and a full service comparison matrix table.
4. **Gallery (`gallery.html`)**: Interactive category filtering (*All*, *Lawn Care*, *Landscaping*, *Sod Installation*, *Cleanup*) and an interactive modal lightbox.
5. **Contact / Quote (`contact.html`)**: Interactive quote request form with client-side validation, error messaging, preferred contact methods, and immediate confirmation state.

---

## ⚡ Technical Highlights

- **Pure Semantic HTML5, CSS3 & Modern JavaScript** — Zero framework bloat, instant page loading, and 100% lighthouse optimization.
- **Mobile-First Responsive Design** — Optimized for both mobile devices (390px) and large desktop screens (1440px+).
- **Interactive Modals & Drawers** — Smooth mobile navigation drawer, quick quote modal accessible across all pages, and photo lightbox viewer.
- **Client-Side Form Validation** — Real-time validation for required fields, email formatting, and 5-digit ZIP codes with custom confirmation cards.

## 🚀 Local Setup & Preview

1. Clone this repository:
   ```bash
   git clone https://github.com/wavendigitalbus-ux/landscapedemo.git
   cd landscapedemo
   ```

2. Open `index.html` in your web browser, or launch any local server:
   ```bash
   python -m http.server 3000
   ```
   Navigate to `http://localhost:3000`.
